# 飞行棋设计规范

已确认的 Pixso「飞行棋」包含 11 个画板。真实设计入口与索引仅保留在本地配置，不随仓库发布。

- 大厅和候场：Q版奶油玩具风、圆润小飞机与骰子、薄荷绿操作按钮。
- 棋盘：彩色格底与圆形留白中心，规则拓扑由 `../shared/board.js` 定义。
- 飞机：四色同款Q版俯视素材，原色不透明，加浅色衬底与柔和阴影，不与彩色棋盘进行正片叠底。
- 移动：逐格前进、跳跃、捷径、折返按实际路线播放，机头对准前进方向，编号不旋转。
- 桌面、834×1194平板与390×844手机都需保持正方形棋盘与清晰的操作反馈。

完整偏好与协作约束见 `../AGENTS.md`，素材来源及提示词见 `aircraft-q.md`，颜色和尺寸令牌见 `tokens.json`。

早期探索图、用户棋盘参考与 Pixso 生成导出仅留本地，不进入 GitHub 或服务器发布包。早期生成图中的错误格数、航线和飞机数量不能作为实现依据。
