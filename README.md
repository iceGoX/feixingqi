# 飞行棋

基于原生 HTML/CSS/JavaScript 与 Node.js 内置模块的飞行棋网站，无第三方运行依赖。支持 2～4 人好友房、同屏游戏、刷新后继续同屏游戏、在线状态同步与服务器存档恢复。

协作规范与 UI 偏好见 [AGENTS.md](AGENTS.md)。

## 设计与规则

- Pixso「飞行棋」设计包含 11 个画板；真实文件链接与索引仅保存在本地配置中。
- 大厅与候场采用已确认的 Q 版奶油玩具风，棋盘采用彩色格底与圆形留白中心。
- 用户规则：`rule.md`；具体执行约定：`RULES_IMPLEMENTED.md`。
- `shared/board.js` 是棋盘坐标、颜色、航道和飞行线的唯一数据来源；`shared/engine.js` 由在线服务器与同屏客户端共同复用。
- 双人模式每人控制两种相对颜色、8 架飞机；同一玩家不互撞，异色不能叠成一组。叠子确认后持续整体移动，撞回机场时解除。

## 移动动画

- 飞机采用 Pixso 已固定的四色 Q 版俯视图集，机头在行进前对准目标，停稳后朝向下一格；编号保持正向。素材来源和提示词见 `design/aircraft-q.md`。
- 普通走步每格约 190 毫秒，逐格轻跃；同色跳跃约 440 毫秒，捷径飞行约 680 毫秒。终点超出时先到终点，再逐格折返。
- 动画使用规则引擎返回的移动阶段，不改变骰子、碰撞、叠子或胜负规则。叠子一起移动，撞机在对应落点回机场，抵达动画后显示结算。
- 同屏与在线共用动画。在线连续状态按版本排队，HTTP/SSE 重复消息不会重播或打断；播放中锁定行动，后台标签页、断线跨版本或减少动态效果设置直接同步当前棋盘。

## 本地开发与构建

使用 Node.js 22 或更新版本，生产运行时为独立安装的 Node.js 24。

```bash
npm run dev -- --host 127.0.0.1 --port 4186
npm test
npm run check
npm run build
```

构建输出在 `dist/`。构建过程校验 JavaScript 语法并生成 `release.json`，以 SHA-256 固定发布内容；不会打包设计文件、测试、环境配置、Git 元数据或 `.data/` 房间存档。

## 部署与隐私

构建产物支持 `/feixingqi/` 子路径。真实域名、服务器和设计文件配置不随代码发布；部署时由本地配置提供。现有私有部署脚本、运行记录和设计索引保留在 Git 忽略路径中。

验收脚本必须显式传入目标地址，不会默认访问任何生产服务器：

```bash
node tools/public-smoke.mjs "$FEIXINGQI_URL"
```

推送前检查暂存区和提交历史。敏感词清单保存在不上传的 `.local/privacy-terms.json` 中，格式为 `{"terms":["需要禁止上传的文本"]}`。缺少该清单时检查会停止，需在本地配置。为当前克隆启用检查：

```bash
git config core.hooksPath .githooks
npm run privacy:check
node tools/privacy-check.mjs --history
```

检查输出只报告文件/对象与命中类别，不回显敏感原文。仓库内容与代码审查结论见 `REVIEW.md`。

## 房间与安全边界

- 昵称为 1～12 字，房间代码为六位字母数字。玩家令牌保存在当前浏览器标签页会话中，不放入邀请链接；服务器存档仅保存令牌哈希。
- 在线骰子由服务器安全随机数生成；行动使用 `expectedVersion` 和 `requestId` 防止过期提交及重复掷骰。前端不能指定点数。
- 在线使用带认证头的 SSE；断线时暂时禁用操作，重连后同步真实状态。等待房间 2 小时、游戏中 24 小时、结束后 1 小时无有效状态更新则回收，在线连接不延长 TTL。
- 全局最多 200 个房间、同一来源 IP 最多 12 个，限制请求体、频率与 SSE 连接。没有进行大规模并发压测。
- 首次完整加载并缓存后可使用同屏离线模式；首次访问仍需下载网页素材。在线好友房需要网络。
- 同屏游戏保存在当前浏览器，不能跨设备恢复。在线房间可在服务重启后恢复，但清除浏览器标签页会话会丢失该标签页的玩家身份。
